# 📋 Descriptions about the project usage
📂First arrange the project folder as the structure shown above. All of the programming codes files are already attached above. Just download and start using.

</> Then create 'index.html', 'intro.css', 'intro.js', 'constellation.css', 'global.css' and 'constellation.js'. Then connect the CSS and JS files script on the index.html; already attached in the script code. 
Then same as it for the rests (puzzle, memory, terminal and book).

💾 You have to just download the files uploaded in repository sequencely, and then connect to each other.You have to just create a new directory 'assets' in the main root (/love-project) folder and then again create a new directory 'photos' in the assets folder (/love-project/assets).

So then, the folder structure for photo files becomes (/love-project/assets/photos); then set your photos path in the book.html; first you have to copy or mv the photos into that '/assets/photos' folder because it's the directory path for book.html, then inside the photos directory-mv yours photos here and then replace the photo file name in the book.html
